## Security

The public repository must not contain MQTT passwords, private keys, permanent tokens, secret-bearing enrollment URIs or private Meshtastic Channel URLs.

## Release state

This repository is prepared for the 2.3.0 external test cycle. GitHub Actions remains the authoritative environment for Android/Windows compilation and release artifact generation.


## 2.3.0 Android application bundle installation

The `.ftak` deployment may bundle ATAK-CIV, the Meshtastic Android app and ATAK plugins. Field TAK Hub checks the bundled versions and launches Android installation/update in sequence. User confirmation is required; silent installation is not claimed.

Canonical paths: `payload/atak/atak.apk`, `payload/apps/meshtastic.apk`, `payload/plugins/*.apk`.
