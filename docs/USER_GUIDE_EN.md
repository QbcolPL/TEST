# Field TAK Hub 2.3.0 — Smart Diagnosis and Recovery

## Smart Diagnosis
On the home screen choose **CHECK EVERYTHING**. Hub checks the important parts and shows a simple result. Users do not need to understand technical terms.

## Recovery
When something needs attention, choose **FIX MY PHONE**. Hub reapplies the currently loaded package and checks the setup again. Recovery does not manually change radio settings and does not contain secrets.

For technical details use Advanced mode.
