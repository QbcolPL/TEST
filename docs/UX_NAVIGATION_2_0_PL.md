# UX i nawigacja 2.0

Ekran główny ma być użyteczny dla zwykłego gracza bez dostępu do narzędzi technicznych.

```text
FIELD TAK HUB

Stan telefonu 87%
ATAK          ✓
Pluginy       !
Dane ATAK     ✓
OpenTAK       ?

[ DOKOŃCZ KONFIGURACJĘ ]
[ SZCZEGÓŁY / CHECKLISTA ]
[ SKANUJ NOWY QR ]

Diagnostyka | Historia
```

`Diagnostyka` otwiera tryb serwisowy. Aplikacja utrzymuje własny lekki stos ekranów; systemowy Back usuwa bieżący ekran ze stosu i wraca do poprzedniego widoku zamiast przypadkowo minimalizować aplikację.
