# Field TAK Hub 2.3.0 — Smart Diagnosis i Recovery

## Smart Diagnosis
Na ekranie głównym wybierz **SPRAWDŹ WSZYSTKO**. Hub sprawdza najważniejsze elementy i pokazuje prosty wynik. Użytkownik nie musi znać nazw technicznych.

## Recovery
Jeżeli coś wymaga uwagi, wybierz **NAPRAW MÓJ TELEFON**. Hub ponownie zastosuje bieżącą paczkę i sprawdzi konfigurację. Recovery nie zmienia ręcznie ustawień radia i nie zawiera sekretów.

Dla szczegółów użyj trybu zaawansowanego.
